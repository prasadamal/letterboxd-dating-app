# Google Play — Data safety (draft answers)

Use these when filling the Data safety form. Adjust if your production deployment changes.

| Question | Answer |
|----------|--------|
| Collects data? | Yes |
| Data encrypted in transit | Yes (HTTPS) |
| Users can request deletion | Yes (email support) |

### Data types

| Type | Collected | Shared | Purpose |
|------|-----------|--------|---------|
| Email address | Yes | No | Account |
| Name | Yes | No | Profile |
| User IDs | Yes | No | Account |
| Other user-generated content (bio, messages, ratings) | Yes | No | App functionality |
| App interactions (ratings) | Yes | No | Matching |

Optional / not collected in MVP: location, photos, contacts, financial info, health, precise device IDs for ads.

### Security practices
- Data encrypted in transit
- Users can request account deletion
