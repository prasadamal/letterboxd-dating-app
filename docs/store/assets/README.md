# Store screenshot & graphic assets

Generate before upload:

| Asset | Size | Notes |
|-------|------|--------|
| App icon | 1024×1024 PNG | `mobile/assets/icon.png` (replace with final brand) |
| Google Play feature graphic | 1024×500 PNG | Dark background #0d1016, ReelMates logo, tagline |
| Android phone screenshots | ≥1080×1920 | Login, Daily picks, Matches, Chat |
| iPhone 6.7" | 1290×2796 | Same flows |
| iPhone 6.5" | 1242×2688 | Optional second set |

**Capture flow**
1. Run API + `cd mobile && npx expo start`
2. Open on device/emulator
3. Screenshot each tab
